# Twemoji graphics

The PNG files in this folder are the 72x72 set of **Twemoji**,
taken unchanged from <https://github.com/jdecked/twemoji> (tag `v15.1.0`,
folder `assets/72x72`).

<https://creativecommons.org/licenses/by/4.0/>
(full text in `LICENSE-CC-BY-4.0.txt`).

File names are the emoji's Unicode code points in lowercase hex joined
by `-`; `fe0f` is usually omitted (loaded by `nagmon/ui/emoji.py`).
