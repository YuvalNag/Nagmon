# נגמון: התקנה והפעלה (מדריך להורים)

## התקנה

### Windows
1. מתקינים Python מ־[python.org](https://www.python.org/downloads/) (גרסה 3.12 או חדשה יותר). בהתקנה מסמנים **Add python.exe to PATH**.
2. מורידים את המשחק מהריפו: בגיטהאב לוחצים **Code ← Download ZIP**, ופורסים לתיקייה, למשל `C:\Nagmon`.
3. לוחצים פעמיים על **`run_nagmon.bat`**.
   - בפעם הראשונה ההתקנה לוקחת כמה דקות, כי היא מורידה את מה שהמשחק צריך.
   - מהפעם השנייה המשחק עולה מיד.

### Linux
```bash
git clone https://github.com/YuvalNag/Nagmon.git
cd Nagmon
./run_nagmon.sh
```

### טלפון אנדרואיד (Poco F3 וכל אנדרואיד 7 ומעלה)
**פעם אחת: מפתח חתימה.** בלי המפתח, כל גרסה חדשה דורשת למחוק את הקודמת, וזה מוחק גם את ההתקדמות של הילדים.
1. במחשב עם Java מריצים:
   ```bash
   keytool -genkeypair -v -keystore nagmon.keystore -alias nagmon \
     -keyalg RSA -keysize 2048 -validity 20000
   base64 -w0 nagmon.keystore > nagmon.keystore.b64
   ```
2. בגיטהאב: **Settings ← Secrets and variables ← Actions ← New repository secret**. מוסיפים שלושה סודות:
   - `ANDROID_KEYSTORE_BASE64`: התוכן של `nagmon.keystore.b64`.
   - `ANDROID_KEYSTORE_PASSWORD`: הסיסמה שבחרתם.
   - `ANDROID_KEY_ALIAS`: `nagmon`
3. את `nagmon.keystore` שומרים במקום בטוח, ולא בריפו.

**בניית האפליקציה:**
1. בגיטהאב: **Actions ← Android APK ← Run workflow**. הבנייה הראשונה לוקחת בערך שעה, והבאות מהירות יותר.
2. בסוף הריצה, תחת **Artifacts**, מורידים את `nagmon-android-…`. זה קובץ zip ובתוכו ה־APK.

**התקנה בטלפון:**
1. מעבירים את ה־APK לטלפון (כבל, Drive או הודעה לעצמכם) ופותחים אותו.
2. בפעם הראשונה אנדרואיד שואל אם לאשר התקנה ממקור לא ידוע. מאשרים לאפליקציה שממנה פתחתם את הקובץ (למשל "קבצים").
3. ב־Poco/Xiaomi ייתכן שתופיע גם בדיקת אבטחה של MIUI. ממשיכים בהתקנה.
4. הפתיחה הראשונה לוקחת חצי דקה עד דקה, כי המשחק פורס את התוכן. מהפעם השנייה הוא עולה מהר.

**משחק בטלפון:**
- המשחק לרוחב.
- נוגעים בכפתורים, בתשובות ובאותיות.
- במפה מופיעים חיצים משמאל, ו־A/B מימין.
- כפתור "חזרה" של הטלפון פותח את תפריט המשחק או סוגר תפריט.
- **הקראה:** קול Google בעברית מובנה בטלפון. אם אין קול: הגדרות ← הגדרות נוספות ← שפה וקלט ← פלט טקסט לדיבור ← מנוע Google ← התקנת נתונים קוליים ← עברית.
- **פרטיות:** הנתונים שמורים רק בתוך האפליקציה. אין גיבוי לענן, ומחיקת האפליקציה מוחקת אותם.

## הפעלה ראשונה
1. **קוד הורים.** בוחרים קוד של 4 ספרות. הוא שומר על אזור ההורים.
2. **שחקן חדש.** לכל ילד: שם (במקלדת העברית שעל המסך), כיתה ודמות. ברירות המחדל של הקושי, הטיימר וההקראה נקבעות לפי הכיתה.
3. **אזור הורים** (הכפתור "הורים" במסך "מי משחק?"):
   - **עיר:** לזמני שבת וחג.
   - **מצב שבת וחג:** המשחק נסגר מכניסת שבת עד צאתה.
   - **דקות ביום ושעות משחק:** 60 דקות ביום, בימי חול 16:00–19:30, ולא אחרי 20:00. אפשר לשנות.
   - **דוח התקדמות** לכל ילד: מה למד, איפה מתקשה, ושאלה לשיחה איתו. ליד כל מספר מופיע הסבר איך חושב.
   - **חגיגות הפתעה:** מגדירים חגיגה שרק ההורים רואים. המשחק מודיע כשהגיע הזמן לחגוג (על מאמץ, לא על הישג).
   - **הינשוף החכם:** הדלקה וכיבוי, וקריאת כל השיחות.
   - **קולות מהאינטרנט:** קול עברי איכותי (Microsoft). דורש אינטרנט, ונשלח רק טקסט המשחק.

## הקראה בקול (חשוב לילדים צעירים)
- **בלי אינטרנט:** ב־Windows מוסיפים קול עברי: הגדרות ← זמן ושפה ← דיבור ← הוספת קולות ← עברית. ב־Linux: `sudo apt install espeak-ng`.
- **עם אינטרנט:** באזור ההורים מדליקים "קולות מהאינטרנט". הקול טבעי יותר.
- **בדיקה:** `python -m nagmon.tts.cli "שלום" --lang he`

## בינה מלאכותית (רשות)
- **בלי מפתח** הינשוף עונה מעשרות תשובות מוכנות, וכל המשחק עובד.
- **מפתח חינמי של Groq** (מומלץ לשימוש של ילדים: לא מאמנים על המידע). נרשמים ב־console.groq.com, ומדליקים שם Zero Data Retention. אחר כך מריצים במחשב:
  ```
  python -m nagmon.keys_cli set groq המפתח_שלכם
  ```
- **מפתח Gemini** (חינמי, מ־AI Studio): לסטודיו התוכן של ההורים.
  ```
  python -m nagmon.keys_cli set gemini המפתח_שלכם
  ```
  תנאי השימוש של Gemini אוסרים שימוש באפליקציה שילדים משתמשים בה. לכן ברירת המחדל היא שהינשוף של הילדים לא משתמש ב־Gemini.
- **סטודיו תוכן** (ההורה מייצר שאלות וסיפורים חדשים ומאשר כל אחד):
  ```
  python -m nagmon.ai.studio --help
  ```

## איך משחקים
- **בקרב:** לפני התקפה מופיעה שאלה מהמקצוע של סוג המפלצת. אש היא חשבון, אדמה היא גאומטריה, מים הם מדעים, ורגיל או גיבור הם אנגלית.
  - תשובה נכונה = מכה קריטית.
  - טעות = התקפה רגילה, והסבר קצר איך פותרים.
  - תמיד אפשר "התקפה בלי שאלה".
- **בלכידה:** תשובה נכונה מגדילה את הסיכוי. מפלצת נדירה דורשת שלוש תשובות.
- **רמז / לא יודע/ת / הקראה:** קיימים בכל שאלה.
- **כוכבי ידע:** על שליטה אמיתית במיומנות. הם פותחים התקדמות בעולם.

## בעיות
- **המשחק לא עולה:** פותחים חלון פקודה בתיקיית המשחק ומריצים `.venv\Scripts\python.exe run_tuxemon.py`. הודעת השגיאה תופיע שם.
- **שמירות ונתונים:** כל ילד שומר בנפרד, בתיקיית המשתמש של Tuxemon, תחת `nagmon/profiles/<ילד>/`.
