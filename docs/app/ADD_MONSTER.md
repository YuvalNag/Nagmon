# הוספת חיה

מה צריך כדי שחיה חדשה תיכנס למשחק: תיקייה אחת לכל חיה, עם קובץ הגדרות ושלוש תמונות.
את השאר (מהלכים, קול, סטטיסטיקה, התמונות בגודל של המשחק, הקרדיטים) אני משלים, ובדיקה אוטומטית מוודאת שהכול מתאים.

## 1. התיקייה

```
<slug>/
  monster.json   ההגדרות (תבנית: docs/app/templates/monster.json)
  front.png      מלפנים: כך היריב רואה אותה בקרב
  back.png       מאחור: כך הילד רואה את החיה שלו בקרב
  icon.png       הראש בלבד, לתפריט
```

- מעלים לריפו הפרטי, לתיקייה `art_inbox/<slug>/` (גרירה לדף של GitHub מספיקה), ואז כותבים לי "העלתי".
- שרשרת התפתחות: תיקייה לכל שלב, וכל שלב מפנה לשלב הבא ב־`evolves_into`.

## 2. התמונות

| קובץ | גודל | הערות |
|---|---|---|
| `front.png` | לפחות 192×192, ריבועי | רקע שקוף או מג'נטה (`#FF00FF`) אחיד. החיה כולה בתמונה, הרגליים למטה |
| `back.png` | כמו `front.png` | אותה חיה בדיוק, מאחור. מותר שהתחתית תיחתך |
| `icon.png` | לפחות 72×72, ריבועי | הראש או הפנים |

- אותו סגנון כמו החיות הקיימות: פיקסל־ארט, קו מתאר כהה, צבעים חיים.
- אפשר גם גיליון אחד עם שלושתן. אז כותבים ב־`images` את שם הקובץ, ואני חותך.
- צניעות: בלי סמלים דתיים. דמות אנושית או דמוית אדם: לבוש צנוע, שרוול עד המרפק לפחות, בלי חצאית קצרה.

## 3. השדות ב־`monster.json`

| שדה | חובה | מה זה | ערכים |
|---|---|---|---|
| `slug` | כן | מזהה באנגלית, אותיות קטנות וקו תחתון | `dropling` |
| `name_he`, `name_en` | כן | השם בעברית ובאנגלית | |
| `description_he`, `description_en` | כן | משפט או שניים, עד 120 תווים | |
| `types` | כן | סוג אחד או שניים. הסוג קובע את המקצוע שהשאלות בקרב שלה שואלות | ראו הטבלה למטה |
| `stage` | כן | השלב בשרשרת | `basic` (ראשונה), `stage1`, `stage2`, `standalone` (בלי התפתחות) |
| `evolves_into` | לא | למי מתפתחת ובאיזו רמה | `{ "slug": "...", "at_level": 16 }` או `null` |
| `evolves_from` | לא | ממי התפתחה (נבדק מול השלב הקודם) | slug או `null` |
| `shape` | לא | צורת גוף, משפיעה על המהלכים | `blob`, `humanoid`, `flier`, `sprite`, `hunter`, `brute`, `varmint`, `serpent`, `dragon`, `grub`, `polliwog`, `landrace`, `piscine`, `leviathan` |
| `height_cm`, `weight_kg` | לא | לטקסט במגדיר | מספרים |
| `where` | לא | איפה פוגשים אותה בטבע | `map`: `route1` (היום רק זה); `levels`: [מ־, עד]; `rarity`: `common`, `uncommon`, `rare`; `time`: `any`, `day`, `night` |
| `moves` | לא | המהלכים לפי רמה | `"auto"`: אני בוחר מהלכים מהסוג שלה. או רשימה: `[{"level": 1, "move": "ram"}]` |
| `images` | כן | שמות הקבצים | |

- חיה של **עברית** היא חריג: כותבים `"subject": "hebrew"` בקובץ, והיא שואלת עברית מכל סוג (כמו גלילון ומגילון).
- המקור של הטבלה: `mods/nagmon/learning/subjects.yaml`.

## 5. מה קורה אחרי "העלתי"

1. בדיקה של הקובץ והתמונות: שדות חסרים, שרשרת שבורה, גודל, רקע, צניעות.
2. המרה לפורמט של המשחק (`mods/nagmon/db/monster/<slug>.yaml`, השמות והתיאורים ב־`nagmon.po`) והתמונות בגודל HD של המשחק (גיליון 384×264).
3. החיה נכנסת לאלבום הדמויות לאישור, ורק אחרי האישור לבנייה.
