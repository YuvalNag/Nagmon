# Export rules for tools/migrate/export_snapshot.py
#
# One rule per line:  "- pattern" leaves a path out, "+ pattern" brings it back.
# The LAST rule that matches a path wins; a path no rule matches is kept.
# A pattern names a file or a folder (a folder takes everything below it).
#   *  any characters except "/"      **  any characters including "/"
# Lines starting with "#" and blank lines are ignored.
#
# What the new repo (nagmon-game) is: the app (app/), the data build that
# makes app/public/game (tools/app + the mods + the two Python packages the
# build imports), the Python tests of that build (tests/app), the app's docs
# and its CI workflow. Measured with a file-access trace of
# `build_data --check` and `pytest tests/app` on nagmon-app 884b9b6, then
# proved by a clean-room dry run (docs: tools/migrate/README.md).
