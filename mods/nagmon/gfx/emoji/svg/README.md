# Twemoji graphics (vector)

The SVG files in this folder are the same **Twemoji** pictures as the PNGs
one folder up, as vectors, so the game draws them sharp at any size
(docs/kids/SDD_FIGURES.md). Taken unchanged from the npm package
`@twemoji/svg` version 15.0.0 (packaging MIT, `LICENSE-package.txt`).
Pictures added in Twemoji 15.1 have no SVG here and use the PNG.
